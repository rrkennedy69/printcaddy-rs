# Round 9 — look, themes, settings, projects, updates

Approved out of order so the page is usable. Rounds 6–8 stay closed. The AI helper is not part of this app: it is not built, and it is not a deferred item.

Rounds 1–5 stay as they are. New bodies are still `#8A98A6`.

## Layout

The left panel keeps every tool, in the same groups as the TypeScript toolbar: Shapes, Sketch, Combine, Arrange. A colour row paints the selection. It does not change the default for a new body. Check for updates sits in the bottom-left corner and opens a window.

## Themes

Dark is the default. Light, Graphite, Night Vision, Thermal, X-Ray, Blocks, Forge, and Works recolour the panels, the plate, and the grid. X-Ray draws bodies see-through on a dark purple plate. The choice is remembered in this browser.

## Settings

Theme, and Mobile mode. Mobile mode enlarges the on-screen handles and the buttons. Languages, the shortcut editor, inches, simple mode, and the rest of the TypeScript settings sections stay later.

## Projects

Save, open, rename, and delete in this browser. Export and import a project file. The file holds the bodies, sketches, groups, holes, and colours. It does not hold the undo stack: opening a project starts undo from empty.

## Updates

The window fetches the published page and compares its build with this one. The same build says so. A newer build offers Reload.

## Google Drive

Sign-in uses the same Google token client and Drive app-data scope as the TypeScript site, and that site's existing public client. No new client is created. If Google refuses this origin, the window says the existing client must allow `https://rrkennedy69.github.io` as a JavaScript origin.
